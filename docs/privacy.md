# Privacy and network access

Local Markdown editing does not require an account, activation service or telemetry account. Tern nevertheless has specific network-capable features: remote images, explicit URL import, optional AI/MCP requests and an optional installed Copilot CLI. This page describes implementation boundaries, not a completed independent privacy/security audit. Use [SECURITY.md](../SECURITY.md) for sensitive reports.

## Local data

Your notes remain ordinary files at the locations you choose. Attachments and linked files may live beside them or elsewhere. Saved-text history, workspace/session state, recovery checkpoints and indexes can contain document text, paths or writing context; treat backups and shared machine accounts accordingly.

| Data | Default location |
| --- | --- |
| Settings and connection metadata | `%APPDATA%\Tern` |
| State | `%LOCALAPPDATA%\Tern` |
| Recovery | `%LOCALAPPDATA%\Tern\recovery` |
| Search indexes | `%LOCALAPPDATA%\Tern\index` |
| Saved AI credentials | Windows Credential Manager |

`TERN_DATA_ROOT` redirects file-based state to separate `settings`, `state`, `recovery` and `index` directories. It does not relocate Windows Credential Manager. Back up notes and important state before cleanup; clearing recovery can remove the only recoverable copy of unsaved work. Removing an application or profile directory does not automatically remove saved credentials.

Version history keeps a copy of the version already on disk when you first save over it, so it can contain text that predates your edits. Deleted-file history stays on disk for 30 days and is size-capped by a setting. Optional diagnostic logging (environment variable `TERN_DIAGNOSTIC_LOG=1`, off by default) writes `diagnostics.log` in the state folder with UTC times, status severity, exception types and method-only stack traces. It excludes status/action text, exception messages, document content, credentials and stack source-file paths. The current log rotates at 512 KiB with one previous `.old` log. An unavailable log does not interrupt normal feedback. Remove the environment variable before launching Tern to stop logging. Reports explicitly copied from the error banner are different: they include error messages and may include paths or other sensitive context, so inspect them before sharing.

## Protected secondary copies and Private workspaces

New saved-text History, recovery checkpoints and seven-day discarded-draft copies use Windows **DPAPI CurrentUser** protection. They can be unlocked by processes with that Windows user's authority; this is not protection against the signed-in user or a replacement for encrypted notes/backups. File names, origin paths and workspace/session metadata are not encrypted. Older plaintext copies remain readable and are not bulk-encrypted automatically. Clear their history explicitly when needed.

Use **File → History and recovery → History Privacy → Change Workspace Privacy…** to mark a named workspace Private. The confirmation explains that source notes remain ordinary, unencrypted files. Save or close dirty workspace notes first. The workspace reopens, removes associated History/recovery/discarded copies and its previous index, and uses an in-memory search database with memory-only SQLite temporary storage. Future History, recovery and Don't save copies are suppressed, including associated untitled drafts after switching away. Private notes have no crash/Don't save safety net.

**Clear History for This File…** and **Clear History for This Workspace…** permanently remove associated saved versions, including recycled versions; they never delete source notes. Cancel is the default. Unknown metadata, unreadable recovery copies and permission/link failures are reported; Tern does not claim those copies were removed. Normal future saves can create new protected versions unless Private remains enabled.

Private is not a network-denial setting: explicit export, print, URL import, approved AI requests and external applications retain their own privacy rules. It does not erase preexisting downloads, external backups, filesystem history, Windows paging/crash dumps or printer spools. Use Offline and review those separate operations when needed.

## Remote images

**Remote images default to Ask.** Preview, HTML/PDF export and print preparation use one document-scoped consent policy. The document banner offers **Load once** for the current session or **Always for this file** for a saved file. **Settings → Privacy and network → Remote images → Never** blocks requests even for previously approved files; Always allows remote images without another prompt. Hosts can observe the requested URL and source network address, and a URL can itself contain sensitive information. Persistent approvals store a hash of the file path and creation identity, not image URLs. Moving a file or saving a new copy requires fresh approval.

The **Offline** status-bar toggle (also in Settings → Privacy and network) blocks remote images regardless of consent, URL import, AI, MCP and Copilot. It cancels pending URL imports. Local editing and local resources remain available. It cannot recall information already transmitted. Help answers have no network image loader. Clicked external links launch separate applications under their own policies; use the external-link setting to prevent those launches. Installed-package offline acceptance remains a separate native check.

The live image loader is bounded: public HTTP/HTTPS destinations, guarded DNS/redirect handling, no supplied authentication/cookies/proxy, at most three redirects, 15-second timeout, four concurrent requests, byte/pixel bounds and format validation. It rejects private/loopback destinations for this path. SVG has stricter limits and active/external content restrictions. Live image bytes are not a persistent offline cache; URL-import bundles below are different. These guards do not make untrusted remote content universally safe.

## Explicit URL import

Open from URL fetches a reviewed Markdown-file URL. Public GitHub file links can become raw-content links. Explicit localhost URLs are supported for this import path, unlike the remote image loader. Public destinations cannot redirect into private/loopback networks; credential-bearing URLs and unsafe redirects are rejected. The loader uses bounded requests without browser cookies or automatic account login.

The Markdown limit is 10,000,000 bytes. Supported directly referenced assets can be cached in a bundle bounded at 128 assets/100,000,000 bytes total. Complete bundles reopen offline; partial bundles report missing assets and can retry. Editing the imported draft does not upload to the server. See [URL import usage](user-guide.md#open-from-url).

Up to four dependencies download concurrently, with a two-minute deadline for the complete import. Open online tabs use the immutable files on disk instead of retaining every compressed asset in memory. Startup cleanup expires superseded cache snapshots older than seven days; current snapshots and snapshots leased by an open tab are preserved. Use Reset Tern to remove retained downloads after closing those tabs.

## Optional AI connections

Settings → AI connections offers API, GitHub Copilot and MCP server choices in one service menu. API connections support chat-completions-compatible, Ollama native-chat or Claude Messages protocols. Saved API, Copilot and MCP connections share the main toolbar; MCP offers a manual tool workspace rather than a writing model. Endpoints require HTTPS, with HTTP allowed for loopback development services. A familiar model name does not establish that the endpoint is genuine, compatible or included in your subscription. Live provider/model compatibility remains separately unverified.

Connection metadata is file-based; saved keys use Windows Credential Manager under per-connection `Tern.AI/…` targets. Unsaved keys remain in memory. Do not paste real keys into Markdown, screenshots, test fixtures, issues or logs. Provider authentication and retention policies remain those of the selected service.

Writing can reuse a successful connection check for up to 30 seconds in the current session, only with unchanged settings and a matching credential fingerprint. Each generation still checks the destination, credentials and target note. A failure invalidates that check. Reusing a check does not reuse note content or send it automatically. HTTP connections can be pooled, while authentication stays on each individual request and cookies remain disabled.

**Every AI request starts fresh**, including retries, across Explore, writing, the prompt panel, Help, Learn Tern, report preparation and connection tests. Email copied from a ready report is built locally and does not make an AI request. Tern sends its instructions, the current task and only the current task material that step needs. It does not append earlier questions, assistant replies or transcripts, resume a provider conversation or reuse a previous-response identifier. The current job's note parts, extracted facts or edited draft may be supplied explicitly as task data. If a large report cannot finish in one reply, independent requests complete smaller source sections and their checked evidence is combined; those requests do not continue a chat session. Reopening a local task is separate from a provider session. A new task or different workspace cannot inherit another task's evidence. These rules control Tern's outgoing requests, not the provider's retention policy.

For API services, Tern sends its rules in the supported instruction field and the current request and source material as user content. Notes and derived facts are untrusted data to examine, not instructions to follow. Copilot receives clearly labelled rules, task and data in its single prompt. Tern does not manufacture an assistant message or send previous answers as chat history.

Opening, navigating, saving and reloading profiles make no network request. **Validate connection** deliberately sends Tern's test instructions and the fixed message `Reply with exactly: OK.` to the configured generation endpoint using the selected model and credential. No note or custom question is attached to this test; provider usage and charges may apply. A successful test confirms that request, not future availability. Explicit model discovery can also contact the endpoint. Before sending other text, review the selected connection, model and content:

- **Generate for review** sends your instruction and either the selected text or the entire note. Check the scope and connection shown in the composer first. The response becomes an undoable edit only if you apply it.
- **Explore your notes** requires an AI connection. It searches one selected workspace locally, including current unsaved overlays. No note text is sent until you press **Get my answer**. When AI use is allowed, **Find my notes** always sends your question so AI can suggest other words for it. AI then sees the file names, titles and headings of up to 16 possible notes so it can choose which to tick. Note text is not sent at that step. Answers and A4 reports read all the notes you keep ticked, up to 1,000,000 characters per question. The question, note text, names, headings and any documented release dates are sent in parts when needed, together with facts combined from earlier parts. For a simple one-fact question, AI may start with the best sections and read the full ticked text if those do not answer it. Tern shows what AI read and names unread notes or unread ends of notes above the total. File saved dates are separate from release dates. Each part fits the selected connection's saved Characters to send at one time value. If a service refuses a size, Explore halves the request size, down to 8,000 characters, without changing that saved value. Tern prepares and checks the complete current report, including your edits, against its current source evidence before it is ready. Changing only the sharing format reuses that checked result without rereading note text or making another AI request. Changed report content or sources require a new check. If that check finds issues, **Ask AI to correct these issues** explicitly sends the current full report, the exact issues and the current notes in a fresh request. The proposed correction must pass quotation, evidence and whole-report checks before becoming a new draft for your review; it never exports automatically. A failed or out-of-date correction keeps your previous wording and issues. **Copy for email** builds an executive-summary email on this computer from the current checked report. Copying it does not send the report to AI or ask AI to paraphrase it again. It does not send an email or attach a file. If a search finds nothing, AI receives the question and Tern's reason so it can suggest what to try next. AI suggestions for a broad or not-found question send only the question. Online AI stays off until you allow it in Settings or with **Yes, use online AI**.
- **Unfinished Explore tasks** are scoped to their workspace. In a normal workspace, a local checkpoint protected with Windows **DPAPI CurrentUser** can contain your question, note choices, source evidence, answer, report edits and pending output. It lets Tern return to the last stage after closing the window or restarting the app. It does not store connection secrets. Processes acting as your signed-in Windows user can unlock it; this is not protection against that user. In a **Private** workspace, unfinished tasks stay in memory only and are removed when Tern closes; no task checkpoint is written to disk. Reopening never contacts AI. Successful copying or exporting keeps the task available until you choose **Done**; **Ask a new question** starts a new task. An interrupted step waits for **Retry**. Changed or missing sources require **Refresh notes** before evidence is reused, while your report wording is kept. Workspace, connection and Offline changes require renewed access and size checks. No embedding service is used.
- Source identities and content are checked when preparing a result. Local source-freshness checks still guard reuse, source navigation and output; changed or missing notes block reuse and require **Refresh notes**. Changing only the output format does not send another request to AI. Exact quotations, headings and line locations are checked against the source text and its content fingerprint. AI checks the whole report rather than just the short answer. Email uses that checked report locally. **Preview report** opens the formatted report locally without another AI request. These checks do not prove every model claim or conclusion is true. Related notes are separate suggestions, not factual evidence. Clearing a local task cannot remove material already received or retained by a provider.
- **Completed Explore tasks:** after all wanted output actions, **Done** automatically removes the task checkpoint and releases cached source text, report and prepared PDF; **Ask a new question** does the same for the previous task. Saved PDFs, inserted notes and other saved outputs are never removed by task cleanup. While a task remains open, its checked cache supports additional formats. Closing its window releases the window's cache but keeps unfinished work in the protected checkpoint or Private workspace memory. This is ordinary deletion and memory release, not a secure-wipe guarantee. A failed checkpoint removal is shown as a warning.
- **Suggest related notes** retains its separate reviewed-passage flow. **Find passages** searches locally; **Send reviewed request** transmits the displayed topic/passages and relative source metadata.
- **Guide questions** send the current question and relevant installed guide facts without attaching the active note or earlier questions and answers.
- **Characters to send at one time** is saved separately for each AI connection. New connections start at 256,000. Older connections without a saved value receive 256,000 once. Connections with a saved value keep it. The allowed entry range is 8,000 to 1,000,000. Every AI request uses the chosen connection's value, including Help, Learn Tern and connection tests. All instruction and data text counts, including the connection-test instructions; the value is not an allowance for user text alone. Write with AI does not split a note: it warns before sending oversized text. Explore may send several parts and combined facts, so the total text shared can be larger than one request. Lowering a value does not recall text already received by a service. MCP tool servers do not have this field.
- Cancellation cannot recall text already transmitted. Undo can revert a local edit, not a provider's receipt or retention of data.

AI API request timeouts can be set per connection under Advanced: 1–3,600 seconds, or blank for 120 seconds at remote endpoints and 300 seconds at loopback endpoints. This applies to generation, validation and model discovery. AI and MCP honor the system proxy without automatically supplying account credentials; remote images and URL imports retain direct, guarded connections. Proxy operators may observe connection metadata under their own policies.

The adapters use bounded, non-streaming requests and response limits. Local protocol fixtures validate request/response contracts; they are not live-service certification or proof of content quality. Review generated text before saving or executing anything it suggests.

## Manual MCP tools

The implementation targets MCP **2025-11-25 Streamable HTTP**, with initialization, tool listing and manually requested tool calls. It does not claim newer-protocol compatibility, stdio support, OAuth or autonomous tool execution.

Named MCP settings can be saved in `integration-connections.json`; optional saved bearer tokens use Windows Credential Manager and are not included in metadata JSON. Loading or saving makes no request. Selecting a saved server in the main toolbar and choosing **Open MCP tools** loads the selected server without sending the note or automatically connecting. MCP selection disables note-generation controls. **Connect and discover tools** initializes the server and lists tools without running one. Review the exact endpoint, selected discovered tool and JSON arguments before calling it. Optional bearer credentials, bounded responses and local request validation do not neutralize a tool's authority. A tool can change an external system; Tern's Undo cannot reverse that. Do not send private note contents as tool arguments unless authorized. HTTPS is required except explicit loopback HTTP development endpoints.

## Optional Copilot CLI

The optional integration invokes a deliberately selected installed `copilot.exe`; it is not a bundled service or entitlement. It uses a bounded reviewed prompt with a separate temporary working/configuration context, and requests that tools, MCP, hooks, updates and instruction discovery be disabled. It does not grant the CLI automatic workspace context. Named CLI/model settings can be saved in `integration-connections.json`; saved tokens use Windows Credential Manager and unsaved tokens stay in memory. Tokens are passed to the child process environment rather than arguments or metadata JSON. Opening, loading and saving make no request. **Validate connection** sends a fixed test message through the selected CLI and model without attaching a note; provider usage may apply. A separate question requires a review and send action. Selecting saved Copilot in the main toolbar also supports writing and guide questions. **Generate for review** sends a fixed validation test followed by the reviewed request if its target and connection are current. Applying a suggestion creates one undoable edit. Copilot requests use the connection's saved Characters to send at one time value and reject @mentions and CLI commands; the composer identifies the scope of the text shared and the connection. Guide questions do not automatically include the active note.

The implementation's expected CLI contract still needs live compatibility verification. External CLI behavior and provider data handling are outside Tern's sole control. Keep it disabled when that boundary is unsuitable for your documents.

Reviewed prompt text is written to the selected CLI’s redirected standard input and is absent from process arguments. Tokens remain in the child process environment. This removes note text from Tern’s process-argument path; it does not control the external CLI’s internal storage or provider retention. The prior handoff records stdin prompt-mode verification with CLI 1.0.90; current regression fixtures verify the process-input contract without live credentials.

## Temporary print PDFs

**Print preview… → Print…** renders the selected formatted PDF pages in memory and sends them through the Windows print dialog to the chosen printer; no PDF reader is required. Windows and the printer driver may spool document content according to their own retention policies. **Open selected PDF…** instead writes `%TEMP%\Tern\PrintPreview\<random>.pdf` for your external reader. These files contain document text and are readable by processes running as your Windows user. Tern removes its own handoff PDFs when the preview closes and removes generated previews older than one day at startup. Cleanup failures are reported; a reader holding a file open or denied permissions can leave a PDF behind. Unrelated files and linked folders are not swept.

## Active content and external links

Preview is native rather than a browser web view. HTML/SVG processing restricts active content; Markdown scripts are not executed as web-page scripts. This is not a guarantee that every hostile input is harmless. Clicking a permitted external link can launch another application/browser, whose policies apply independently.

Use synthetic inputs for testing network behavior and remove secrets, personal paths and document text from shared diagnostics. The [release ledger](V1_RELEASE_LEDGER.md) separates static/source checks from runtime offline and native acceptance.
