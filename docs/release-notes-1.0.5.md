# Tern 1.0.5

Tern 1.0.5 improves first-note guidance, everyday authoring dialogs and printing.

- Welcome and Help → Tern Quick Start share a design and a catalog of ten professional starter templates. Hide Quick Start tips persists without replay clearing the preference; samples, templates and guides remain available in an empty workspace.
- New blank notes, samples and templates use CRLF. Existing files preserve detected line endings.
- Reading task checkboxes have complete borders and check marks. Print Preview displays actual PDF pages from the printable output.
- Mermaid connections with small alignment drift use straight connectors where both node faces permit it. Intentional rounded branches, distinct connection ports and feedback loops remain.
- Metadata focuses on adding, editing and clearing tags. Apply tags edits the buffer; Save writes the file. Unrelated metadata is preserved.
- Insert link separates Web address, Local file and Heading in this note, with destination-specific validation.
- Unsaved image insertion offers Save note and Cancel before a file picker. Save cancellation or failure stops insertion. Replacing an existing attachment requires explicit confirmation of its path.
- The editor formatting toolbar no longer includes AI or its flyout. Create content is removed from Write with AI. Other AI commands and connections remain available.
- Ask & learn explains offline guide retrieval before submission when no AI connection exists. Generated answers require a compatible connection.
- Print Preview uses an aligned, responsive toolbar. All, Current page and mixed page ranges control both preview navigation and output. Changing the selection clears stale output status; obsolete asynchronous output is never opened. Open selected PDF contains only selected pages; the PDF reader retains printer and copies settings.
- Windows setup includes a license agreement, folder selection, optional Start menu and desktop shortcuts, an Install confirmation and optional Launch Tern on Finish. The Tern icon is registered for Windows Installed apps. Setup uses Segoe UI, concise headings and Tern-branded header and welcome artwork.
- Windows x64 distributions include a per-user MSI, standalone Tern.exe and complete portable ZIP. Explorer integration applies to .md and preserves the current default app.

See [1.0.5 workflows](user-guide.md#version-105-workflows). Signature status and remaining native acceptance checks are recorded with each candidate. Automated tests do not prove compatibility with every printer, display scale, security policy or device.
